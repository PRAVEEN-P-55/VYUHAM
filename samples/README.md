# Synthetic evidence samples

These files are fictional, upload-ready demonstration records. They contain no real case or personal data.

## Handwritten Hindi

Upload [`handwritten-hindi/FIR0002.png`](handwritten-hindi/FIR0002.png) through Document Intake to exercise the Hindi processing workflow.

The current demonstration pipeline uses seeded metadata associated with the sample filename. OCR, translation, and entity extraction are simulated pipeline stages, so this sample validates the upload, processing, evidence listing, and graph-update interface rather than production handwriting recognition accuracy.
